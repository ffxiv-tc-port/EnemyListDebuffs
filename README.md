# EnemyListDebuffs

在敵人列表（Enemy List）上以圖示＋倒數計時顯示自身對每個目標施加的持續傷害／減益狀態，方便多目標戰鬥時追蹤。

## 功能

- 敵人列表每個目標旁顯示對應的減益狀態圖示與剩餘時間
- 可從右側開始填滿圖示
- 可調整圖示群組縮放比例

## 安裝

在 Dalamud 設定的「自訂插件庫」加入
`https://raw.githubusercontent.com/ffxiv-tc-port/DalamudPluginsTC/main/repo.json`
並啟用，再從插件列表安裝。
